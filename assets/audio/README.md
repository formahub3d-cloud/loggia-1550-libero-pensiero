# Audio del Tempio

Carica qui i file audio per la musica ambientale del sito.

## Nomi file richiesti

- **`temple-ambient.mp3`** — formato principale
- **`temple-ambient.ogg`** — fallback (opzionale)

## Come caricare da GitHub

### Da browser/mobile
1. Click su "Add file" → "Upload files" qui sopra
2. Trascina il/i file
3. Commit changes (in fondo alla pagina)

Il sito si aggiorna automaticamente in 30-60 secondi.

## Cambiare il brano
1. Carica il nuovo file con lo stesso nome `temple-ambient.mp3`
2. GitHub Pages rideploya da solo
3. I visitatori sentiranno il nuovo brano al prossimo refresh
   (potrebbero dover svuotare la cache del browser)

## Specifiche tecniche

| Parametro | Valore consigliato |
|-----------|-------------------|
| Durata | 2-5 minuti (sarà in loop) |
| Bitrate | 128-192 kbps |
| Sample rate | 44.1 kHz |
| Volume | -14 LUFS normalizzato |
| Peso | 2-7 MB |
