=============================================
AUDIO AMBIENTALE DEL TEMPIO
=============================================

Il sistema cerca DUE file possibili (in ordine):

  1. temple-ambient.mp3  ← formato consigliato (ampia compatibilità)
  2. temple-ambient.ogg  ← fallback opzionale

ISTRUZIONI:
1. Ottieni un file audio royalty-free o di tua proprietà
   (es. da Pixabay, freesound.org, opslaboratorio.it, o un .mp3 tuo)
2. Rinominalo "temple-ambient.mp3"
3. Mettilo dentro questa cartella (assets/audio/)
4. Ricarica il sito: il bottone audio in basso a destra suonerà il file

CONSIGLI:
- Durata almeno 2-3 minuti (verrà riprodotto in loop)
- Formato MP3 a 128-192 kbps (peso ragionevole, qualità sufficiente per ambient)
- Volume normalizzato a -14 LUFS circa (non sovrabbondante)
- Suoni adatti: drone basso, ambient, gregoriano, organo, vento, oppure
  registrazioni esoteriche/templari/medievali

DOPO IL DEPLOY SU SITEGROUND:
- Il file resterà in questa stessa cartella
- Verrà servito via HTTPS al posto di file://
- Funzionerà sia da desktop che da mobile
